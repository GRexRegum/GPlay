# 🌸 GeoVN Portal — ქართული ვიზუალური ნოველების პორტალი

თანამედროვე, ვიზუალურად დახვეწილი და სრულად ქართულენოვანი ვებ-პორტალი ვიზუალური ნოველების თარგმანების გამოსაქვეყნებლად, გადმოსაწერად და პროგრესის სამართავად.

---

## ✨ ძირითადი შესაძლებლობები (Features)

1. **სრულად ქართულ ენაზე (100% ქართული ინტერფეისი)**:
   - ყველა ღილაკი, აღწერა, ჟანრი, სტატუსი და ფორმა შექმნილია გამართული ქართული ენით.
   - ლამაზი ქართული ფონტები (Google Fonts: Noto Sans Georgian).

2. **ვიზუალური ეფექტები (Anime & Visual Novel Aesthetics)**:
   - **საკურას ფურცლებისა და ნაპერწკლების ცვენა (Canvas)**: რეალისტური 3D რხევა და მაუსის მოძრაობაზე რეაგირება (ჩართვა/გამორთვის ღილაკით).
   - **Glassmorphism & Cyber-Dark თემატიკა**: მინისებრი ბარათები, ნეონის (Sakura Pink, Cyan, Violet) ნათებები და გლუვი hover ანიმაციები.
   - **ინტერაქტიული აუდიო (Web Audio API)**: მშვიდი ემბიენტ მუსიკა და ინტერფეისის სასიამოვნო ხმოვანი ეფექტები გარე მძიმე ფაილების გარეშე.

3. **ნოველების კატალოგი და მართვა**:
   - სტატუსის ფილტრები: *ყველა*, *დასრულებული (100%)*, *პროცესშია*, *დაგეგმილი*.
   - ჟანრებით ფილტრაცია და ცოცხალი ძიება (სათაური, ორიგინალი სახელი, ავტორი).
   - თარგმანის პროგრესის მაჩვენებელი (% ტექსტი, % მენიუ, % გრაფიკა, % ტესტირება).

4. **დეტალური მოდალური ფანჯარა (Modal)**:
   - სინოფსისი (სიუჟეტი), სქრინშოთების გალერეა.
   - პატჩის გადმოსაწერი ბმულები (Google Drive, Mega, Steam Workshop და ა.შ.).
   - ქართული პატჩის დაყენების ეტაპობრივი გზამკვლევი.

5. **კონტაქტი და უკუკავშირი**:
   - ფორმა შეცდომების შესატყობინებლად, ახალი ნოველის შესათავაზებლად ან გუნდში გასაწევრიანებლად.
   - შეტყობინებები ინახება ბრაუზერის `localStorage`-ში (`geo_vn_messages`).
   - სოციალური ბმულები (Discord, Telegram, Facebook, YouTube).

## 🚀 როგორ გავუშვათ საიტი? (Quick Start)

### ვარიანტი 1: მყისიერი გაშვება (ყველაზე მარტივი)
* უბრალოდ ორჯერ დააკლიკეთ ფაილს **`start.bat`** ან პირდაპირ გახსენით **`index.html`** თქვენს ბრაუზერში (Chrome, Edge, Firefox, Opera)!

### ვარიანტი 2: ლოკალური HTTP სერვერით
თუ გსურთ საიტის გაშვება `http://localhost:8080` მისამართზე:
* გახსენით PowerShell და გაუშვით:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\server.ps1
  ```

## 💬 უკუკავშირის ფორმის დაკავშირება (Discord Webhook / Email)

ამჟამად კონტაქტის ფორმა შეტყობინებებს ინახავს მომხმარებლის ბრაუზერში (`localStorage`).
თუ გსურთ, რომ შეტყობინებები პირდაპირ თქვენს **Discord არხზე** მოვიდეს Webhook-ით:
`scripts/app.js`-ში `fetch` ფუნქციით შეგიძლიათ გააგზავნოთ მონაცემები თქვენს Discord Webhook URL-ზე:
```javascript
fetch("თქვენი_DISCORD_WEBHOOK_URL", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    content: `📢 **ახალი შეტყობინება საიტიდან!**\n**სახელი:** ${name}\n**ელ-ფოსტა:** ${email}\n**თემა:** ${subject}\n**შეტყობინება:** ${message}`
  })
});
```
